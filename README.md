# 📊 Project Evaluation Analyzer

A Python-based data analysis project that evaluates and compares student project performance using **NumPy** and **Pandas**.

## 🎯 Project Overview
The Project Evaluation Analyzer processes student evaluation data across four criteria:
- Quality
- Innovation
- Presentation
- Teamwork

It calculates individual average scores, evaluates performance, applies weighted scoring, and identifies the top-performing projects.

## 🛠️ Technologies Used
- **Python** – Core programming language
- **NumPy** – Numerical calculations and statistical operations
- **Pandas** – Data handling, analysis, filtering, and sorting
- **Jupyter Notebook** – Writing and executing the analysis

## ✨ Key Features
- Reads and analyzes CSV datasets
- Inspects dataset structure and data types
- Checks missing and duplicate records
- Calculates average scores using NumPy
- Creates calculated columns using Pandas
- Filters and sorts student performance
- Calculates weighted scores based on evaluation criteria
- Identifies the top 3 projects
- Exports the final analysis into a CSV report

## ⚖️ Weighted Scoring System

| Evaluation Criteria | Weight |
|---|---:|
| Quality | 30% |
| Innovation | 25% |
| Presentation | 25% |
| Teamwork | 20% |

## 📁 Project Files
- `project_evaluation_analyzer.ipynb` – Main analysis notebook
- `Student_09_dataset.csv` – Input dataset
- `student_report.csv` – Final generated report

## 🚀 Learning Outcomes
This project demonstrates practical use of Python, NumPy, and Pandas for data analysis, along with CSV handling, data manipulation, and performance evaluation.
